# v6_A_0.3 수정 및 검증 기록

검증일: 2026-09-07. 기준 원본: 사용자가 첨부한 `analyzerbykijungnamv6_A_0.2.zip`.

## 화면 오류에서 확인한 사실

첨부 화면은 `app.py`에서 `from trade_engine import Costs, dec, position_size`를 실행하다 ImportError가 발생한 상태입니다. 서버의 구체적인 오류 문장은 가려져 있습니다.

첨부 ZIP의 trade_engine.py에는 세 항목이 모두 있고, 이 ZIP의 원본 계산 테스트 33개와 Streamlit 화면 테스트 2개 스크립트는 로컬에서 통과했습니다. 따라서 **첨부 ZIP 자체에서 동일 ImportError는 재현되지 않았습니다.** 배포된 파일의 버전 혼합, 다른 파일을 가져오는 경로 문제, 실행 프로세스에 남은 이전 모듈은 가능한 원인이며, 실제 서버 로그 없이 하나로 단정하지 않습니다.

이번 버전은 계산 구현을 `trade_core.py`로 옮겨 앱·Trade Lab·새 체결 검증이 직접 사용하도록 했습니다. `trade_engine.py`는 기존 호출을 위한 호환 연결만 남겼습니다. 이전 trade_engine 모듈이 프로세스에 남아 있고 필요한 함수가 전혀 없는 상황을 테스트에서 재현한 뒤, 새 앱과 Trade Lab이 정상 작동함을 확인했습니다. 새 파일이 누락되면 앱에 전체 파일 재업로드·재시작 안내를 표시하고, 실제 예외는 서버 로그에 남깁니다. 파일이 없어도 계산을 대체하거나 임의 수치로 진행하지 않습니다.

## 실제 수정 사항

| 항목 | 수정 내용 |
|---|---|
| 배포 오류 대응 | 독립된 trade_core 사용, 누락 시 한국어 안내, 파일 무결성·함수 가져오기 검사 추가 |
| 과거 검증 캐시 | 버전·종목·기준점수뿐 아니라 주가와 비교지수의 실제 데이터 내용까지 반영. 같은 날짜의 수정 시세도 이전 결과를 재사용하지 않음 |
| 검증 실패 후 표시 | 재계산 시 기존 동일 조건 결과를 먼저 제거해 실패한 뒤 과거 성공 결과가 남지 않음 |
| 한국 종목 예비 검색 | ZIP에 없는 top10_ranking 참조를 실제 포함된 scanner_engine으로 수정. 모든 조회 경로 실패 시 기본 종목 검색 테스트 추가 |
| Streamlit 호환성 | 폐기 예정 use_container_width 호출을 width="stretch"로 변경 |
| 의존성 | 실제 테스트한 직접 의존성 버전을 requirements.txt에 고정. 전이 의존성 전체 잠금은 아님 |
| 배포 확인 | release_manifest.json, verify_release.py, GitHub Actions 검증 설정, 업로드 안내 추가 |

## 새 체결 조건 검증

기존 종가 대비 5·10·20·60일 성과 통계와 분리된 기능입니다. **과거 진입 검증 실행 → 다음 날 시가 · 손절·목표 체결 검증 → 체결 조건 검증 실행** 순서로 사용합니다.

- 신호일 종가까지 계산한 Entry 점수와 그날의 손절·1차 목표가를 저장합니다. 진입 이후 손절·목표를 미래 정보로 다시 계산하지 않습니다.
- 다음 거래일 시가에 진입합니다. 시가가 손절가 이하 또는 목표가 이상이면 진입하지 않고 제외 사유를 남깁니다. 현재 화면의 지정 진입가를 기다리는 주문 모델은 아닙니다.
- 각 전략은 별도로 평가하며 한 포지션을 보유하는 동안 같은 전략의 추가 신호는 제외합니다. 청산일 종가 신호로 다음 날 다시 진입하는 것은 허용합니다.
- 손절 아래 갭 하락은 해당 시가로 청산합니다. 목표 위 갭 상승은 보수적으로 목표가에 체결합니다. 하루에 두 가격을 모두 건드리면 손절이 먼저 일어났다고 가정합니다.
- 진입 당일부터 최대 보유기간을 세고, 손절·목표에 도달하지 않으면 마지막 날 종가로 청산합니다. 최대 보유기간 전체 데이터가 있는 신호만 평가해 최근에 빨리 청산된 사례만 선택하는 편향을 피합니다.
- 매수·매도 수수료, 매도세, 양방향 불리한 체결오차를 기존 Decimal 계산 엔진으로 반영합니다. 기본 비용은 0이며 사용자가 설정합니다.
- 개별 거래 순수익률의 평균·중앙값·최저값, 순이익 사례 비율, 체결·제외 사유와 CSV를 제공합니다. 계좌 복리수익률, 포지션 비중, 계좌 MDD를 계산하는 기능은 아닙니다.
- 가격의 결측·비정상 범위·중복 날짜는 건너뛰어 결과를 꾸미지 않고 오류로 안내합니다.

## 클로드 평가 대조

사용자가 붙여 준 평가는 검토 참고자료로 사용했습니다. 언급된 `claude/v6_A_0.2-review.md` 파일은 첨부 ZIP에 없었습니다.

기존 33개 계산 테스트 통과를 재현했고, 클로드가 실행하지 못했다고 밝힌 `test_trade_ui.py`, `test_analysis_ui.py`도 실제 Streamlit AppTest로 통과했습니다. N+1 종가 수익률, 12M 이력 부족, 평탄한 가격의 ADX, 매매비용·수량 제한, Wilson 참고구간과 동일 날짜 비교지수 매칭은 원본 구현과 테스트에서 확인했습니다. 이번 수정에서 해당 계산식은 유지했습니다.

클로드가 지적한 실제 체결 조건의 부재는 위의 제한된 일봉 체결 모델로 일부 보완했습니다. 과거 시장점수 50 고정, 근사 환율 1,350을 이용한 한국 유동성 구간 판단, 현재 구성종목 중심 검증의 한계는 남아 있습니다. app.py의 전면 분리는 하지 않았고 새 기능을 별도 모듈로 추가했습니다.
