# v-6d_0.1 — 2026-09-12

Streamlit 개인 테스트 버전의 첫 구현입니다.

- 여섯 메뉴와 종목 이동, 뉴스에서 종목 분석 연결.
- 기존 V6.0.22 계열 엔진을 별도 패키지로 보존.
- 한국·미국 실제 자료 조회 및 65초 수집 시간 제한.
- 조회 실패 시 마지막 정상 자료 유지, 조회 상태 표시.
- 관심종목·가설·메모·추적 일정의 SQLite 지속 저장.
- 분석 입력·엔진 버전·결과 보존, 중복 저장 방지, 판단 추가 기록.
- 재접속 후 마지막 분석과 차트 복원.
- 종목별 실적 예정일 조회, 경제·기업 일정 수동 등록.
- 뉴스·수집 시각은 KST로 표시. 일정의 정확한 발표 시각은 미확인으로 유지.

확인: 미국 MU 501개·한국 삼성전자 484개 일봉을 이용한 실제 분석과 저장 성공(가격 기준 2026-09-11). 뉴스는 두 기업 각각 12건 조회. 이 수치는 연결 확인용이며 수익 성과 검증이 아닙니다.

자동 테스트: 저장 후 재접속, 실제 Streamlit 위젯 이동, 분석 상세 탭, 일정 추적, 입력 부족, 한국 거래대금 환산, 과거 기록 보호, 중복 분석, 조회 실패 시 캐시 유지 등 9개 테스트 통과.

현재 범위: 단일 사용자 로컬 실행. 후보 찾기는 선택 종목의 가격 비교. 경제지표 자동 수집, 옵션·동종기업 상대평가, 자동 뉴스 번역·AI 해석, 로그인·외부 알림, 계좌 연동, Strategy Lab 전체 검증은 다음 개발 영역입니다.
