# 분석기 by kijungnam V3.1.4

V3의 설명 가능한 상세 분석을 유지하면서 시장 대시보드, 회사명 검색, AI 눌림목, 지지·저항 차트, 추천 진입 참고가격대와 기간별 수익률을 통합한 Streamlit 웹앱입니다.

## 주요 기능

- 종합점수 해석 및 상세 산출근거
- 긍정요인·주의요인
- 장기·단기 추세점수와 계산근거
- 펀더멘털·테크니컬 세부점수
- 추세·AI 눌림목·지지/저항을 결합한 추천 진입 참고가격대
- 진입 적합도, 현재가 위치, 무효화선, 목표선, 예상 보상/위험 비율
- 최근 7일·1개월·3개월·1년 가격 변화율
- 투자기간별 참고점수와 시장 대비 상대강도
- ATR 기반 지지·저항 구간, 강도, 근거 및 대응 시나리오
- AI 눌림목 점수, 추천 진입구간, 무효화선, 목표 참고선
- 통합 차트에 지지·저항·추천 진입구간 표시
- S&P 500, Nasdaq 100, SOX, VIX 장중 미니차트
- 미국채, 원자재, 신용시장, 환율·가상자산 패널
- 티커 및 회사명 검색 후보 선택
- 핵심 뉴스 3건 요약
- PC·태블릿·모바일 반응형 레이아웃

## 진입 참고가격 계산 방식

추천 진입 참고가격대는 아래 요소를 결합해 계산합니다.

- 장기·단기 추세 점수
- AI 눌림목 점수
- 가장 가까운 지지구간의 강도
- 20일 이동평균선 위치
- ATR 변동성
- 다음 저항구간과 무효화선

가격대는 자동 계산된 참고구간이며 투자 권유나 체결 보장을 의미하지 않습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```
