# 로고 서체 후보

1. **Roboto Serif Black Condensed** — 기본. OFL, wght=900, wdth=75, opsz=48. [공식 저장소](https://github.com/googlefonts/roboto-serif).
2. **Bodoni Moda Black** — 획 대비가 더 큰 선택지. [OFL 파일](https://github.com/google/fonts/tree/main/ofl/bodonimoda).
3. **Source Serif 4 Black** — 덜 장식적이고 단단한 선택지. [공식 저장소](https://github.com/adobe-fonts/source-serif).

사용자 선택 전에는 1번. 로고는 SVG 글리프 윤곽이므로 기기에 해당 폰트가 없어도 동일하게 보인다. `scripts/build_logos.py`와 함께 원본 폰트/OFL을 보관한다. 개인용 블루 #6698C9, 공개용 라임 #C4F750, 잉크 #12150E는 ADDENDUM의 명시값을 따른다. 공개 로고의 415×445 구성과 내부 정사각형 비율은 참고 JPG를 유지한다.

본문은 [Pretendard v1.3.9](https://github.com/orioncactus/pretendard/releases/tag/v1.3.9), OFL. woff2와 라이선스를 앱에서 직접 제공하며 외부 글꼴 CDN에 의존하지 않는다.
